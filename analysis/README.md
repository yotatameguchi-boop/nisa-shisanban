# 重回帰分析：円建てリターンは予測できるのか

このツールは予測モデルを持たず、実績データをブートストラップしている。
その設計判断が正しいかを確かめるために、「年末時点で分かっている情報から翌年のリターンを
説明できるか」を重回帰で検証した。**結論は、できない。**

```bash
pip install -r requirements.txt
python3 build_dataset.py   # データ統合（Shillerの元データは自動取得）
python3 regress.py         # 回帰（結果は report.txt）
python3 charts.py          # 作図（regression.png）
python3 block_length.py    # ブロック長の検証（結果は block_length.txt）
python3 regress_acwi.py    # 全世界版の回帰（結果は report_acwi.txt）
python3 charts_acwi.py     # 作図（regression_acwi.png）
```

![回帰結果](regression.png)

## データ

`../data/` の3系列（S&P500配当込み・MSCI World ex USA・ドル円年末）に加え、
[Shiller の長期データ](https://shillerdata.com/)から CAPE・配当利回り・米10年金利・CPI を取得。
元ファイル（1.6MB）は同梱せず `build_dataset.py` が取りに行き、使う年次系列だけを
`../data/shiller-annual-1871-2025.csv` に残す。標本は **1972〜2025年の54年**、欠測なし。

## 結果

### 1年先は予測できない

被説明変数は翌年の円建てS&P500リターン。説明変数は年末時点で観測できる7つ
（CAPE益回り・配当利回り・米10年金利・期間スプレッド・インフレ率・当年の為替変動・当年のリターン）。

| | 値 |
|---|---:|
| R² | 0.081 |
| **自由度調整済 R²** | **-0.062** |
| F検定 | p = 0.218 |
| 有意な変数 | **なし**（最小 p = 0.148） |
| 残差の標準偏差 | 23.3% |

自由度調整済R²が負ということは、**説明変数を7つ入れたモデルが、ただの平均値より説明していない**。
標準誤差はNewey-West（系列相関・不均一分散に頑健）。

### 10年先の説明力も見せかけ

CAPE益回り・配当利回り・米10年金利で10年先の年率リターンを説明すると R²=0.360 まで上がる。
だがこれは本物ではない：

- 単変数だと **R² は 0.002〜0.067** しかない（EY 0.027／DY 0.051／GS10 0.020）
- CAPE益回りと配当利回りの**相関は 0.978**。ほぼ同じものを測っている2変数が、
  符号を逆（-1.93 と +8.22）にして打ち消し合う形で入っている。VIFは21〜22
- 10年の重複標本なので、n=44 でも**独立な観測は実質4.4個**。Durbin-Watson=0.60

### 標本外では全部が「過去平均」に負ける

1992年以降を1年ずつ、それまでのデータだけで推定して予測した（Campbell-Thompson の標本外R²）。

| モデル | 標本外R² |
|---|---:|
| 全部入り（7変数） | **-0.458** |
| 絞り込み（3変数） | **-0.172** |
| CAPE益回りだけ | **-0.135** |

すべて負。**過去平均を使ったほうが当たる。**変数を増やすほど悪化するのは過剰適合の典型。

### 為替は円建て投資家のリスクの約4割

対数なら `ln(1+円建て) = ln(1+ドル建て) + ln(1+為替)` と厳密に分解できるので、分散も分解できる。

| 要因 | 分散に占める割合 |
|---|---:|
| 米国株そのもの | 60.0% |
| 為替そのもの | 30.1% |
| 両者の共分散×2 | 9.9% |

円建ての年率標準偏差は21.5%。米国株と円安の相関は+0.12でほぼ無相関、
つまり**為替は分散効果をほとんど生まないまま、リスクだけを上乗せしている**。

## この分析がツールに対して意味すること

予測モデルを載せなくて正解だった、ということ。年末の割安・割高も金利もインフレも、
翌年のリターンをまるで説明しない。**だからツールは予測せず、実際に起きた54年を引き直して
「幅」を見せている。**点推定を出さない設計自体が、この回帰結果の裏付けになっている。

一方で為替の分解は、円建てモードを既定にした判断を支持している。
円で投資する人にとって、リスクの4割は為替から来ている。

## ブロック長に根拠はあるのか

ツールは実績データを「1年ずつ / 連続5年 / 連続10年」で引き直せる。**既定は長らく5年だったが、
これは勘で決めた値だった。**[arch](https://github.com/bashtage/arch)（Kevin Sheppard, NCSA License）の
`optimal_block_length` で、データに決めさせた。

### そもそも連ねるべき相関があるのか

| 系列 | ρ1 | ρ2 | ρ3 | ρ5 | Ljung-Box(5) p |
|---|---:|---:|---:|---:|---:|
| 円建て株式（S&P500） | 0.075 | -0.172 | -0.046 | -0.309 | 0.135 |
| ドル建て株式（S&P500） | -0.057 | -0.157 | 0.026 | -0.274 | 0.210 |
| 米10年国債 | -0.068 | -0.023 | 0.157 | -0.047 | 0.714 |
| ドル円の変動 | 0.183 | -0.157 | -0.204 | 0.079 | 0.257 |
| 米国以外の株式 | -0.014 | -0.058 | 0.015 | -0.182 | 0.503 |

**どの系列も「相関なし」を棄却できない。**

### Politis & White (2004) の自動選択

| 系列 | 定常ブートストラップ | 循環ブートストラップ |
|---|---:|---:|
| 円建て株式（S&P500） | **0.97年** | 1.11年 |
| ドル建て株式（S&P500） | 0.97年 | 1.11年 |
| 米10年国債 | 1.10年 | 1.25年 |
| ドル円の変動 | 1.57年 | 1.80年 |
| 米国以外の株式 | 0.35年 | 0.41年 |

**全部およそ1年。**つまり「連ねるな」というのがデータの答え。

### 連ねると結果はどう歪むか

月5万円・25年・円建て株式100％、各20,000回：

| 手法 | 下位10% | 中央値 | 上位10% |
|---|---:|---:|---:|
| 1年ずつ（IID） | 2,346万円 | 6,233万円 | 16,740万円 |
| 循環BS 2年 | 2,307万円 | 6,191万円 | 17,654万円 |
| 循環BS 5年（旧既定） | **2,518万円** | 6,117万円 | **15,724万円** |
| 循環BS 10年 | **2,680万円** | 6,181万円 | **13,979万円** |
| 定常BS 平均5年 | 2,636万円 | 6,172万円 | 14,442万円 |

5年ブロックは下位10%を **+171万円** 持ち上げ、上位10%を **-1,016万円** 削る。10年だと
+334万円 / -2,761万円。**結果の幅を実際より狭く見せる。**
乱数の種を変えただけの誤差は下位10%で ±7万円、上位10%で ±479万円なので、
この歪みはノイズでは説明できない。

原因は年次リターンのわずかな平均回帰（ρ2 = -0.17、ρ5 = -0.31）。連続する実際の年をまとめて
引くと、この打ち消し合いがそのまま入って複利のばらつきが縮む。だが Ljung-Box では
この相関は有意ではない。**統計的に確かめられていないパターンを増幅していたことになる。**

### 対応

既定を **1年ずつ** に変更した。5年・10年の選択肢は残してあるが、
「結果の幅が実際より狭く出る」と画面上に明記している。

## 全世界（オルカン相当）でやり直すと

上の検証は S&P500 を対象にしていた。新興国データが入ったので、NISAで実際に買われている
**オルカン相当の配分（米国65／先進国ex US 23／新興国12）そのもの**で same question をやり直した。
新興国は1990年開始なので**標本は1990〜2025年の36年**に縮む。説明変数7個に対して n=35 は余裕がない。

![全世界版の回帰結果](regression_acwi.png)

### 結論は変わらない：1年先は予測できない

| | 全世界（65/23/12） | 米国のみ（同じ期間） |
|---|---:|---:|
| R² | 0.118 | 0.132 |
| **自由度調整済 R²** | **-0.111** | **-0.093** |
| F検定 | p = 0.281 | p = 0.249 |
| 有意な変数 | なし | なし |

対象をオルカンに変えても、**自由度調整済R²は負のまま**。

### 地域別のリスク寄与

ドル建て部分の分散を地域に割り振ると：

| 資産 | 配分 | 単体の標準偏差 | リスク寄与 |
|---|---:|---:|---:|
| 米国 | 65% | 17.2% | 61.5% |
| 先進国ex US | 23% | 18.9% | 23.4% |
| **新興国** | **12%** | **30.6%** | **15.1%** |

新興国は単体では最も荒い（30.6%）が、配分12%に対しリスク寄与は15.1%にとどまる。
他と完全には連動しないぶん薄まる。**これが分散の中身。**

為替も含めた分解では、全世界株そのものが66.1%、為替が22.7%、共分散が11.2%。
米国だけ（1972–2025）のときは為替関連が約40%だったので、**分散すると為替の比重は下がる**（約34%）。

### ひとつだけ、標本外でも残った関係

**当年の新興国リターンが高いほど、翌年の全世界リターンは低い**（係数 -0.254、p=0.003、単変数R²=0.146）。
この分析で唯一、標本外でも過去平均に勝った（**標本外R² = +0.068**、n=19）。

10年モデルのときのような「見せかけ」ではないかを潰しておいた：

| 検証 | 結果 |
|---|---|
| 単変数だけで回す | 係数 -0.254、p=0.003（他変数との組み合わせ効果ではない） |
| 最も影響の大きい2007年を除外 | 係数 -0.154、p=0.034（残る） |
| 2008・2009年を除外 | 係数 -0.230、p=0.032（残る） |
| **1993年を除外** | 係数 -0.226、**p=0.067（有意性を失う）** |
| 標本外R² | **+0.068**（唯一のプラス） |

また、当年の「全世界自身」のリターンは翌年をまったく説明しない（p=0.757）ので、
単なる平均回帰ではなく新興国特有の動きに見える。

**それでもモデルには採用しない。**理由は3つ：

1. 標本が35年しかなく、1年（1993年）落とすだけで有意性が消える
2. 標本外R²は +0.068。過去平均よりわずかにマシという程度で、点推定を出す根拠にはならない
3. ここまで複数の定式化を試している。試行回数を重ねれば、偶然「効く」変数は出る

ツールは引き続き予測せず、実績を引き直して幅を見せる。

### 10年モデルは今回も見せかけ

R²=0.683、配当利回りと米10年金利が p<0.01 で有意に見えるが、**n=26 の10年重複なので
独立な観測は実質2.6個**。VIFも9.9〜10.9。1972年からの検証と同じ罠で、読む価値はない。
