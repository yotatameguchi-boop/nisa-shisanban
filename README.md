# NISA 試算盤

新NISAの非課税枠を織り込んだ積立の試算ツール。**実際に起きた相場と為替**をブートストラップして、
円建ての資産額の分布を出す。ブラウザだけで動く単一HTMLで、サーバーも依存関係もない。

> **これは計算ツールであって、投資助言ではありません。** 表示される数字は、実績データと入力した
> 前提から機械的に計算した結果です。将来の運用成果を予測・保証するものではなく、特定の銘柄を
> 推奨するものでもありません。

## 三つの計算盤

### 1. 積立シミュレーション

毎月の積立額と期間から、税引後の資産額の分布（10 / 25 / 50 / 75 / 90 パーセンタイル）を出す。
リターンの決め方は2通り。

- **実績データから抽出**（既定）— S&P500・米10年国債・ドル円の実際の年次データから、過去に起きた
  年をくじ引きのように抽出する。**株式・債券・為替は同じ年をまとめて**引くので、三者の実際の
  連動関係がそのまま残る。
  - **通貨**は円建て（為替込み）／ドル建てから選択。既定は円建て
  - **株式の中身**は米国（S&P500）・米国以外の先進国（MSCI World ex USA）・新興国の3つで組む。
    プリセットは「米国」100/0/0 ／「先進国」74/26/0 ／「全世界」65/23/12 ／「米国以外」0/66/34。
    「全世界」は**オルカン（MSCI ACWI）の地域構成そのもの**
  - 期間は円建てなら 1972年〜 / 1990年〜 / 2000年〜、ドル建てなら 1928年〜 / 1946年〜 / 1970年〜 / 1990年〜
    （米国以外を混ぜると1970年以降、新興国を入れると1990年以降に限られる）
  - 抽出は 1年ずつ / 連続5年 / 連続10年（ブロック・ブートストラップ）から選択。**既定は1年ずつ**。
    まとめて引くと「暴落の翌年に何が起きたか」という並び順も再現されるが、年次リターンに
    統計的に意味のある連なりは見つからない（[検証](analysis/README.md#ブロック長に根拠はあるのか)）
- **パラメータ指定** — 期待リターンとボラティリティを自分で決め、対数正規の乱数で回す

#### 新興国を入れても予測はできない

オルカン相当（65/23/12）の円建てリターンで重回帰をやり直しても、自由度調整済R²は **-0.111**、
F検定 p=0.281、有意な変数はゼロ。対象を変えても結論は動かない
（[全世界版の検証](analysis/README.md#全世界オルカン相当でやり直すと)）。

ドル建て部分のリスク寄与は 米国61.5％ / 先進国ex US 23.4％ / 新興国15.1％。
新興国は単体の標準偏差が30.6％もあるのに、配分12％に対する寄与は15.1％にとどまる。

#### 新興国を12％混ぜると何が変わるか

円建て・**1990〜2025年**・株式100％で、月5万円を25年積み立てた場合：

| 株式の中身 | 年率 | 標準偏差 | 最悪の年 | 中央値 | 下位10% |
|---|---:|---:|---:|---:|---:|
| 米国のみ | 10.97% | 22.1% | -48.4% | 7,720万円 | 2,830万円 |
| 先進国（74/26/0） | 9.83% | 21.0% | -49.8% | 6,559万円 | 2,444万円 |
| **全世界（65/23/12）** | **9.91%** | **20.7%** | -51.4% | **6,603万円** | 2,439万円 |
| 米国以外（0/66/34） | 7.24% | 22.3% | -56.8% | 4,521万円 | 1,601万円 |

先進国だけの組み合わせに新興国を12％足すと、**年率が上がって（9.83→9.91％）標準偏差が下がる**
（21.0→20.7％）。新興国は単体では最も荒い資産（年率標準偏差30.6％）だが、先進国と完全には
連動しないため、少量混ぜるとポートフォリオ全体のリスクはむしろ下がる。

ただし効果は控えめで、下位10%は 2,444万 → 2,439万円とほぼ動かない（モンテカルロ誤差の範囲）。
**新興国12％の効き目は「ばらつきが少し下がる」までで、下振れが目に見えて浅くなるわけではない。**

ただしこの期間に限れば**米国100％が中央値で勝っている**。1990〜2025年が米国優位の時代
だったからで、期間を変えれば順位は変わる（1972年から見た比較は下記）。

#### 分散すると何が変わるか

円建て・1972〜2025年・株式100％で、月5万円を25年積み立てた場合：

| 株式の中身 | 年率 | 標準偏差 | 最悪の年 | 中央値 | 下位10% |
|---|---:|---:|---:|---:|---:|
| 米国のみ | 9.64% | 22.4% | -48.4% | 6,057万円 | 2,454万円 |
| **全世界（74/26）** | 9.40% | 20.8% | -49.8% | **5,964万円** | **2,636万円** |
| 米国以外のみ | 8.05% | 19.7% | -53.8% | 4,951万円 | 2,316万円 |

全世界に分散すると**中央値はわずかに下がるが、下位10%は上がる**（2,454万 → 2,636万円）。
分散が効くのは真ん中ではなく下振れのほう、ということが実データで出る。

なお「最悪の年」は分散したほうが悪い。2008年は米国以外（-43.2%）が米国（-36.6%）より
下げたため。**1年の最悪値と、25年積み立てた結果の下振れは別物**で、後者が改善している。

#### 為替を入れると何が変わるか

S&P500 100%、1972〜2025年で比べると：

| | ドル建て | 円建て |
|---|---:|---:|
| 年率リターン（幾何平均） | 11.06% | **9.64%** |
| 標準偏差 | 約17% | **22.4%** |
| 最悪の年 | -36.6%（2008年） | **-48.4%（2008年）** |
| マイナスの年 | 11 / 54年 | **15 / 54年** |

2008年は米国株が -36.6% 下げたうえに、同じ年にドル円が 111.71円 → 90.79円（-18.7%）の円高になった。
円で持っていた人にとっては **-48.4%** の年。**為替はリターンを削るだけでなく、リスクを大きく増やす。**
1971年末から2025年末までの為替の寄与は年率 -1.28%。

非課税枠の扱いは制度どおりに実装している。

- つみたて投資枠 年120万円 ＋ 成長投資枠 年240万円 ＝ **年間360万円**
- **生涯非課税保有限度額 1,800万円**（取得価額ベース）
- 年間枠または生涯枠を超えた分は**課税口座に溢れる**ものとして扱い、その売却益に20.315%を課税する
- NISA活用時と「全額課税口座」の場合を並べて、非課税による差額を表示する

### 2. 信託報酬の生涯コスト

同じリターンを仮定した上で、信託報酬だけを変えたときの最終評価額と支払コスト総額を比較する。
初期値は実在ファンドの実際の信託報酬（下記の出典を参照）。

### 3. 銘柄の序列

コスト・リターン・低リスク・シャープレシオ・純資産規模の5軸に**自分で重みを付けて**、
合計スコアで並べる。積み上げ棒の各セグメントがどの指標の寄与かを示すので、
順位の理由が見える。

**この序列は「買うべき順」ではなく「指定した評価軸で並べた順」。** 正規化は入力した銘柄の
中での最小値=0点・最大値=100点なので、比較対象を入れ替えれば点数は変わる。絶対評価ではない。

## この試算が扱っていないこと

- **円建ては1972年以降だけ** — 1971年8月まで固定相場だったため、為替が意味を持つのは変動相場制以降。
  ドル建てモードは1928年まで遡れるが、こちらは**為替がずっと一定だったと仮定した参考値**で、
  円で積み立てる実態とは合わない
- **為替ヘッジ** — ヘッジ付きファンドのヘッジコストは扱っていない
- **新興国はMSCI指数ではない** — Fama-French の新興国マーケット・ポートフォリオを使っている。
  照合できた年はMSCI EMと近いが（2008年 -53.8％ 対 -53.2％）、構成銘柄も加重も別物。
  また1990年開始なので、新興国を入れると1990年以降しか使えない
- **配分は毎年リバランス** — 株式・債券と、米国・米国以外の比率は毎年末に元の比率へ戻す前提
- **年内の値動き** — 抽出した年間リターンを12等分の複利に均しているため、年の途中の高値・安値は再現されない
- **未知の事態** — ブートストラップは「過去に起きた年が同じ確率で再来する」という仮定。1928年以降に
  一度も起きていない事態は決して現れない
- **インフレ** — 表示金額はすべて名目値。実質的な購買力ではない
- **実質コスト** — 信託報酬のみ。売買委託手数料などの隠れコストは含まない
- **課税タイミング** — 課税口座は「期間の最後に全額売却して一括課税」と単純化している。配当課税は考慮しない
- **個別の判断** — 銘柄の推奨、家計・年齢・リスク許容度をふまえた判断、税務・法務上の助言は範囲外

## 開発

`src/page.html` が本体。Claude Artifacts に公開する前提なので `<!doctype>` や `<head>` を持たない
（ホスト側が付ける）。GitHub Pages などで単体配信するための `index.html` は次のコマンドで生成する。

```sh
./build.sh
```

`src/page.html` を編集したら `build.sh` を流して `index.html` を更新すること。
ライブラリは使っていない。フォントのみ Google Fonts から読み込む。
